## About Me

AI Engineer building practical systems across **machine learning**, **computer vision**, **AI automation**, and **agentic AI**. I focus on taking AI projects from data pipelines through model training to deployed applications and APIs.

My work spans:
- **Computer Vision**: Image classification, object detection, transfer learning, RGB/thermal analysis
- **AI Automation**: Workflow orchestration, tool-calling agents, automated pipelines
- **ML Systems**: End-to-end systems from data processing to model inference to APIs
- **AI Data Operations**: Data annotation, dataset preparation, quality control, model-assisted labeling

Currently building intelligent systems that combine **LLM reasoning** with **deterministic tool execution** for practical AI applications.
